05

3Dインタラクション設計

Three.jsとGSAPを組み合わせた実装方針です。ページは独立したメッシュとして管理し、回転と浮遊のアニメーションで物理的な「めくり」を演出します。

アニメーション仕様

項目 仕様
ページ回転 綴じ目をY軸に、rotation.y を 0 → -π に1.3秒で補間（ease: power2.inOut）
浮遊効果 ページめくり中、position.y を +0.15 上昇させて紙のしなりを演出
Zオーダー管理 めくり中のページを最前面（z = 0.1）、完了後は奥へ再配置
カメラワーク マウス位置に応じた微細な視点移動（振幅 ±0.3）。パースを強調
影 DirectionalLight + SpotLight でページと地面にソフトシャウ
入力対応 ボタン、左右矢印キー、タッチスワイプ（50px閾値）の3方式

ページテクスチャ生成

すべてのページ内容は Canvas API で動的に描画します。これにより、コードのシンタックスハイライト、マークダウンの対比レイアウト、日本語の組版をWebGLテクスチャ上で正確に再現できます。フォト読み込み完了後にテクスチャを生成し、ローディング画面で進捗を表示します。

06

実装ガイドライン

デザイン意図を損なわないための実装上の注意点です。ビジュアルとパフォーマンスのバランスを意識してください。

1

フォントの先行読み込み

document.fonts.ready で Noto Serif JP と Noto Sans JP の読み込みを待ってからCanvasテクスチャを生成します。文字化けを防ぐため必須です。

2

セグメント数の最適化

ページメッシュのセグメントは 64×64 を推奨。カール表現に十分な頂点数を確保しつつ、モバイルでは 32×32 にフォールバックします。

3

テクスチャ解像度

Canvasサイズは 512×700 を基準とします。Retina対応で devicePixelRatio を考慮しつつ、VRAM使用量とのバランスを取ります。

4

アクセシビリティ

prefers-reduced-motion に対応し、減速設定時はアニメーションを無効化。キーボードナビゲーションは必須です。
