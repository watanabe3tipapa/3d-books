プログラム言語とは

プログラム言語とは、コンピュータに指示を出すために人間が使う形式的な言語です。自然言語（日本語や英語）とは異なり、厳密な文法と意味論よって定義されています。

なぜ必要か

コンピュータは0と1の機械語しか理解できません。人間が直接機械語を書くのは非常に困難なため、人間にとって理解しやすい形で指示を記述し、それを機械語に変換（コンパイル・インタープリト）する仕組みが必要でした。

高級言語と低級言語

  • 低級言語：機械語やアセンブリに近い。硬件に依存。
  • 高級言語：人間の言語に近い。Python、JavaScriptなど。

主要なプログラム言語

Python

読みやすさを重視した言語。AI、データ分析、Web開発など幅広く使われています。

def hello():
    print("Hello, World!")

JavaScript

Webページに動的な機能を追加する言語。フロントエンドからサーバーサイドまで対応。

const greet = () => {
    console.log("Hello!");
};

主要なプログラム言語（続き）

Java

「一度書けば、どこでも動く」を理念とした言語。企業システムやAndroidアプリで広く使用。

public class Main {
    public static void main(String[] args) {
        System.out.println("Hello");
    }
}

C / C++

OSや組み込みシステム、ゲームエンジンなど高性能が求められる分野で活躍。

// C++ の例
#include <iostream>
int main() {
    std::cout << "Hello";
    return 0;
}

言語の分類と特徴

パラダイムによる分類

  • 手続き型：C、Pascal など。順番に処理を記述。
  • オブジェクト指向：Java、C++ など。データと処理をオブジェクトにまとめる。
  • 関数型：Haskell、Scala など。関数の合成を重視。
  • スクリプト型：Python、Ruby など。手軽に自動化を実現。

型システム

静的型付け（Java、C）と動的型付け（Python、JavaScript）の2大分類があります。静的型付けは実行前に型チェックを行い安全性が高く、動的型付けは柔軟で開発が速いという特徴があります。

マークダウン記法とは

マークダウン（Markdown）は、John Gruber によって2004年に作られた軽量マークアップ言語です。HTMLなどに比べて読み書きが容易な記法で、プレーンテキストを構造化されたドキュメントに変換できます。

主な特徴

  • プレーンテキストなので、どのエディタでも編集可能
  • ソース自体が人間にとって読みやすい
  • HTMLへの変換が容易
  • GitHub、Notion、Slackなど多くのサービスで採用

なぜ人気か

技術文書の作成、READMEの記述、ブログ記事、メモなど、日常的な文書作成の多くでマークダウンが使われています。学習コストが低く、すぐに実践で使える点が魅力です。

12

活用シーン

GitHub / GitLab

リポジトリのREADME.mdはマークダウン形式です。プロジェクトの説明、インスール方法、使い方、貢献ガイドラインなどを記述します。

技術ブログ

多くの静的サイトジェネレーター（Jekyll、Hugo、Gatsbyなど）はマークダウンを入力として使います。執筆に集中でき、HTMLの煩わしさから解放されます。

ドキュメント

APIドキュメント、マニュアル、社内Wikiなど、構造化された文書の作成に適しています。バージョン管理も容易です。

メモ・ノート

Notion、Obsidian、Bearなどのノートアプリでもマークダウン（またはその拡張）が使われています。

まとめ

プログラム言語はコンピュータとの対話手段であり、目的や分野に応じて様々な言語が存在します。初心者にはPythonやJavaScriptがおすすめです。

マークダウン記法は、技術文書を手軽に作成するための強力なツールです。基本的な記法は数時間で習得でき、すぐに実践で活用できます。

次のステップ

  • 実際にエディタでマークダウンを書いてみる

  • 興味のあるプログラム言語を1つ選んで学び始める
  • 静的サイトジェネレーターでブログを作ってみる
